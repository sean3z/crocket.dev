With an assistant

A program you can still read

The model can write the service. You still have to own it at 2 a.m.

C++ is growing again, driven by AI work like inference: in GitHub's 2025 Octoverse, C++ repositories grew 11.82%, and AI-tagged C++ repositories were up 11%. The old cost of C++ was writing it, and an assistant writes that first draft now. What's left is reading it and running it, which crocket makes easy, and you keep the speed.

An assistant makes the C++ cheap to write. crocket makes it easy to read and run, and you keep the speed.

Why now

  • Octoverse says AI-tagged C++ repositories crossed 7,800, up 11%, on inference and other performance-critical AI work, such as llama.cpp, which is LLM inference in C/C++.
  • The 2025 Stack Overflow Developer Survey says 84% are using or planning to use AI tools, and 45% say debugging AI-generated code is more time-consuming.
  • JetBrains' 2025 survey says 85% regularly use AI tools for coding, and writing boilerplate is what they are most likely to hand off.
  • The language keeps getting easier: C++26 static reflection is what crocket's routes are built on, and the library already has std::expected (C++23), std::format (C++20), and std::print (C++23).

It still gets things wrong

The compile step and the types catch a missing parameter name, a capture that doesn't match, and a return type that isn't a response. They won't catch a minimum of 1 that should have been 0, or an issuer you pasted from an example. Read the diff.
